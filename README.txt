Прототип экрана входа

Как открыть:
1. Убедись, что установлен Python (https://www.python.org/downloads/) — на Windows при установке отметь "Add python.exe to PATH".
2. Запусти start.bat двойным кликом.
3. В открывшемся окне появится адрес — открой в браузере: http://localhost:8080/login.html

Важно: просто открыть login.html двойным кликом (файлом) не получится — страница использует
современные ES-модули (React/Three.js через import map), а браузеры блокируют их загрузку
при открытии файла напрямую (file://). Нужен локальный сервер — для этого и нужен start.bat.

Нужен интернет: часть библиотек (React, Three.js, шрифты) подгружается с CDN, без сети
анимация и шрифты не загрузятся.
